How it works

  • Visits only the company's own public site: the home page and up to {{ config.CRAWL_MAX_PAGES }} linked contact/about/team pages.
  • Obeys robots.txt and crawl delays, waits between requests, and uses short timeouts.
  • Never logs in, solves CAPTCHAs, or gets around paywalls or other protections.
  • Collects only addresses actually written on the page. It never guesses addresses from names.
  • Records the page and date for each result. You review everything before it becomes a contact.

Basic discovery is free and runs on this server. No paid API is used.
